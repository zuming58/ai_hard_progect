02 / CORE

板子的“大脑”和“记忆”

先记住三个词：ESP32-S3 负责计算，Flash 长期保存内容，PSRAM 是运行时的临时工作区。

ESP32
S3R8

ESP32-S3R8 主控

读取按键与旋钮、控制灯光、处理音频、连接 Wi-Fi/BLE，并运行你的固件逻辑。

Wi-FiBLE8 MB PSRAM原生 USB

Flash 和 PSRAM 有什么区别？

Flash · 像硬盘

断电后仍保存固件和资源。本板容量为 16 MB。

PSRAM · 像工作台

运行时临时放数据，断电后内容消失。本板为 8 MB。

批次提醒：设计资料记录 W25Q128 系列，但实拍 U11 字样可能是兼容替代料。容量与用途可确认，具体厂牌暂不写死。
03 / INPUT & OUTPUT

它如何感知，又如何反馈

输入让板子知道你做了什么；输出让板子用灯光和声音回应你。实际业务动作由训练营项目定义。

8 个主按键

S1～S8 是独立低有效输入，不是矩阵键盘，因此可以同时检测多个键。

S1=GPIO2S2=47S3=38S4=41S5=1S6=6S7=7S8=48

旋转编码器

A/B 两相信号错开变化，程序据此判断旋转方向；向下按压则是 S9。

A=GPIO17B=GPIO16S9=GPIO18

灯光反馈

5 颗 WS2812 串联，共用一条数据线；另有一颗独立绿色状态灯。

RGB=GPIO12绿灯=GPIO42顺序=GRB

数字麦克风

声音被数字化后，经 I2S 信号送入 ESP32-S3。

BCLK=9WS=10DIN=11

扬声器输出

ESP32-S3 输出数字音频，板上 MAX98357A 路径负责驱动外接扬声器。

BCLK=14WS=13DOUT=15

汇总唤醒 KEY_WAKE

GPIO21 只能说明“某个输入动作了”，不能告诉你具体是哪一个。唤醒后仍要重新读取独立输入。

KEY_WAKE=21低有效
“低有效”怎么理解？按键平时由上拉保持为 1，按下后接到地，程序读到 0。它并不代表“坏了”或“没有信号”。
04 / POWER

一个很重要的共享电源

GPIO8 不是单独的“灯带开关”。它同时影响 RGB 灯、麦克风和扬声器，软件必须协调三个消费者。

ESP32-S3 输出GPIO8PWR_EN · 高有效
共享外设电源域同开 · 同关稳定后才能初始化外设
5 颗 RGB 灯数字麦克风扬声器功放
STEP 01GPIO8 先锁存为低不要一开始就让共享外设突然上电。
STEP 02命令输出预置为低GPIO9/10/12/13/14/15 先进入安全状态。
STEP 03GPIO8 拉高打开共享外设电源。
STEP 04等待电源稳定当前资料不能给出适用所有批次的固定最短毫秒数。
STEP 05初始化外设再开始灯光、录音或播放。

电池电压与充电状态

测电池

GPIO5 拉高使能分压，再从 GPIO4 / ADC1_CH3 读取约为 VBAT/2 的电压。

看充电

GPIO40 为低表示外部供电存在；此时 GPIO39 高=充电中，低=充满。

为什么电量百分比不一定准？

板上没有专用 fuel gauge。GPIO4 读到的是端电压，电压还会受负载、温度和电池状态影响，因此百分比需要项目自己校准估算。

不要误判：发送 RGB 全黑帧只代表灯灭，不代表 GPIO8 共享电源已经关闭。
05 / BOOT & FLASH

烧录时，只要短按一次

这块板的 BOOT 电路不是普通 ESP32 开发板上的“裸 GPIO0 按键”。请按实板确认过的流程操作。

进入下载模式

保持开发板开机不需要先关机或拔 USB。
短按并松开 BOOT按一次即可，不要一直按住。
等待下载端口出现再让烧录工具连接 ESP32-S3 下载端口。
退出：关机再开机烧录完成后重新正常启动。

不要照搬这些通用教程

关机后按住 BOOT，再上电。
整个烧录过程持续按住 BOOT。
按住 BOOT 的同时按 RESET。
寻找板上并不存在的独立 RESET/EN 按钮。
烧录边界：BOOT 只负责进入下载模式。写哪些分区、是否擦除 Flash，必须由具体项目决定。

08 / TROUBLESHOOT

先拦住最常见的误区

很多问题不是代码难，而是使用了旧版资料、通用 ESP32 教程或把共享资源理解成独立资源。

错误S5 是 GPIO0。
正确S5=GPIO1；GPIO0 专用于 BOOT。
错误GPIO8 只是灯带开关。
正确它同时控制 LED、麦克风、扬声器电源域。
错误5 颗灯占 5 个 GPIO。
正确5 颗 WS2812 串联，共用 GPIO12。
错误KEY_WAKE 能告诉我哪颗键被按。
正确它只表示有输入动作，具体来源要重读。
错误充电状态高代表充满。
正确外部供电存在时，高=充电中，低=充满。
错误按住 BOOT 再上电。
正确开机状态短按并松开一次。
电脑没有出现下载端口怎么办？

依次确认板型、USB 数据线、供电和电脑端口列表；然后保持开机，再短按并松开 BOOT。若仍失败，记录端口变化和日志，不要未经确认退回“按住上电”的旧流程。

为什么灯灭了，麦克风或扬声器仍可能有问题？

灯的全黑帧只改变颜色数据，不会关闭 GPIO8 共享电源。运行中要关电，必须先停止所有 LED、麦克风和扬声器活动，再按安全顺序处理。

为什么电池百分比跳动？

本板没有专用电量计。端电压会随负载、温度和电池状态变化，百分比算法必须由项目校准，单次 ADC 读数不能直接当准确剩余容量。

照片上能看到所有元器件型号吗？

不能。照片适合确认位置、封装和部分丝印，但完整型号、参数与是否装配要以当前批次 BOM、装配资料和测量为准。

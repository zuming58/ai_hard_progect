# 旧 Arduino 物料补充盘点：UNO 与实验板

更新日期：2026-08-19

来源：用户在另一窗口提供的照片识别文字。本文件只记录硬件身份、可复用价值和接线注意事项。文字中的鱼缸场景属于识别错误，用户没有鱼缸项目。

## 已识别硬件

- Arduino UNO R4 WiFi：适合作为独立试验主控，先验证传感器和 UART 协议；最终一体机通常不再作为第三主控。
- YFROBOT Easy Module Mix V1：集成 DHT11、光敏、LED、按键、蜂鸣器和继电器；适合快速原型，不进最终外壳。
- HC-SR04：用于靠近检测和云台左中右扫描；Echo 电平必须确认，接 ESP32 时不得超过 3.3 V。
- ESP32 开发板：保留作独立传感器或通信试验，具体型号和 pinout 待实物确认。
- Sensor Shield V5、Prototype Shield：适合 UNO 原型接线和焊接转接，不可直接插 ESP32。
- DHT11、光敏、LED、按键、蜂鸣器：可用于环境状态、亮度调节和模式交互原型。
- RC522、1602 LCD、Nokia 5110、声音传感器、面包板电源、杜邦线和基础元件：分别用于模式卡、调试显示、触发和台架搭建。
- MQ-2、疑似 NRF24L01 等模块：当前主线不优先，接线前须核对丝印。

## 推荐试验顺序

1. UNO R4 + Easy Module Mix：逐项确认按键、LED、蜂鸣器、DHT11 和光敏。
2. UNO R4 + HC-SR04：记录距离、角度和目标材质对结果的影响，验证滤波与超时。
3. UNO R4 + RC522：验证刷卡切换专注或展示模式。
4. UNO 暂代桌宠副控：接收 IDLE、WORKING、DONE、ERROR，用 LED 或蜂鸣器反馈，提前验证 UART 协议。
5. 桌宠套件到手并确认 GPIO 后，再把有价值的算法迁移到 ESP32-S3。

## 安全边界

- Arduino 常见 5 V 输出不可直接进入 ESP32/EasyInput 的 3.3 V GPIO。
- 舵机使用独立 5 V 电源并与逻辑共地。
- 面包板电源不承担舵机和最终整机供电。
- 继电器只用于低风险原型，不承担市电成品控制。

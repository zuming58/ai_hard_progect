# 桌面宠物感知与 IO 扩展核对

更新日期：2026-08-19

## 一、图片中这类机器人有没有足够 IO

从商品图片可以确认它是一块“带排针和模块接口的 ESP32-S3 桌面机器人主控板”，图上能看到或标注：

- 3.3V、GND；
- TX、RX；
- 一组屏幕/显示相关接口，标注了 `SDA/SCL` 或 `SCS` 等信号；
- 多个 GPIO 排针，图中能看到 28、42、40、41、39、38、23、36、47、21、42、0、5、3、19、6、9、13、12、10、11、8 等数字标记；
- 左侧有舵机、I2S 麦克风、功放或屏幕的专用接口标注。

这说明它的扩展能力明显强于 EasyInput 的 J4 四针调试口，原则上可以接光敏、温湿度、ToF、超声波、触摸等传感器。

但商品图不是完整原理图。当前仍不能仅凭图片确定：

- 哪些 GPIO 已被 OLED、I2S 麦克风、功放和双舵机占用；
- 图中“28、42”等数字是实际 GPIO 还是排针位置/丝印；
- 传感器接口的电压和上拉电阻；
- 舵机电源是否独立；
- 这些接口在卖家源码中的具体定义。

因此，买回来后必须以它的引脚表、原理图和源码为准，不能按图片上“看起来有很多口”直接接线。

## 二、推荐的传感器

### 1. ToF 是什么

ToF 是 Time of Flight 的缩写，中文常叫“飞行时间测距”。它发出红外光，测量光返回所需的时间，从而估算物体距离。常见模块包括 VL53L0X、VL53L1X 等。

它与超声波的主要区别：

| 对比 | ToF | 超声波 |
|---|---|---|
| 原理 | 红外光飞行时间 | 声波回波 |
| 常见接口 | I2C | GPIO 触发 + 回波，部分模块 UART/I2C |
| 体积 | 很小，容易藏进外壳 | 探头较大，外观明显 |
| 方向判断 | 需两个模块或扫描 | 需两个模块或舵机扫描 |
| 桌面近距离 | 响应快、外观整洁 | 能用，但易受角度、软物体和反射影响 |
| 黑色/强光环境 | 可能受影响 | 也可能受材质和环境影响 |
| 适合作品 | 推荐 | 适合已有模块快速验证 |

### 2. 面向人应该怎么做

单个超声波或单个 ToF 都只能测“前面多远”，不能直接判断“人在哪边”。推荐这样设计：

#### 第一版：一个传感器 + 云台扫描

把一个 ToF 安装在桌宠头部，让头部在左、中、右三个角度测距：

```text
左转 30°测距 → 中间 0°测距 → 右转 30°测距
→ 比较三个距离 → 转向距离较近且变化稳定的方向
```

优点是只需要一个传感器，结构简单，能利用已有双轴云台。缺点是头部会周期性扫描，跟随不是连续实时的。

#### 第二版：左右两个 ToF

在屏幕左右各放一个 ToF：

```text
左侧距离更近 → 头部向左转
右侧距离更近 → 头部向右转
距离相近     → 保持中间
```

这是我最推荐的毕业设计方案。传感器很小，能隐藏在屏幕黑色面板里，视觉上可以自然融入“眼睛”或边角。它不是识别人脸，而是根据左右距离差判断用户更靠近哪一侧。

#### 第三版：摄像头跟随

如果以后追求真正的人脸/人体跟随，可以用电脑摄像头或更高算力视觉板识别人的位置，再把目标角度发给 ESP32 桌宠。普通 ESP32-S3 可以做轻量视觉，但不适合一开始承担完整的人脸识别和连续跟踪。

## 三、光敏、温湿度和其他传感器的接法思路

建议优先接在“桌宠套件主控板”上，而不是接到 EasyInput：

| 传感器 | 常见接口 | 适合的产品行为 |
|---|---|---|
| 光敏模块 | ADC 或数字输出 | 自动调屏幕亮度、判断昼夜 |
| 温湿度模块 | I2C 或单线 | 显示环境状态、提醒通风 |
| ToF | I2C | 判断左右方向和距离 |
| 超声波 | GPIO 触发/回波 | 快速验证近距离感知 |
| 触摸模块 | GPIO 或 I2C | 触摸外壳时眨眼、回应 |
| PIR | 数字 GPIO | 判断有人经过或离开 |
| IMU | I2C/SPI | 判断桌宠被移动或倾斜 |

产品设计上不建议“传感器越多越好”。每增加一个传感器，都要对应一个用户能感知的行为，并记录它占用的 GPIO、供电和程序模块。

## 四、EasyInput 与桌宠主控的边界

### EasyInput 适合负责

- 键盘按键和旋钮；
- 板载麦克风和语音输入；
- 原有扬声器和语音反馈；
- AI 任务状态；
- 通过 J4 UART 发送高层事件。

### 桌宠 ESP32-S3 适合负责

- OLED 或彩色屏幕刷新；
- 双轴舵机 PWM；
- ToF、超声波、光敏、温湿度等传感器；
- 表情和动作状态机；
- 传感器采样和局部安全逻辑。

### 两块板之间

只发送高层事件，不发送大量底层 IO 指令：

```text
LISTENING
THINKING
WORKING progress=60 eta=25
USER_LEFT
USER_NEAR
TURN angle=-20
DONE
```

这样即使以后更换传感器或重新分配桌宠主控 GPIO，EasyInput 的主协议也不用全部重写。

## 五、当前建议的硬件路线

1. 先用现成 ESP32-S3 桌宠套件跑通屏幕、双轴舵机和示例源码；
2. 找到该套件的真实 GPIO 表，确认哪些接口空闲；
3. 先接一个已有的超声波模块，做三点扫描验证；
4. 再购买或使用一个 VL53L0X/VL53L1X ToF，比较它与超声波的效果；
5. 最终采用两个 ToF 做左右方向判断；
6. 在一体化外壳上把两个 ToF 藏在屏幕左右边缘；
7. 用 EasyInput 的 UART 把任务状态和语音事件发给桌宠；
8. 根据用户是否在场、左右距离差和任务状态，决定头部角度与表情。

已生成一张“一体式 EasyInput AI 工作台伙伴”产品概念图：

- 前部是低矮的 EasyInput 风格键盘和旋钮；
- 后部是一体化外壳中的双轴桌宠头部；
- 屏幕显示表情和任务进度环；
- 屏幕左右各有一个小型 ToF 感知窗口；
- 键盘和桌宠没有外露跳线或面包板；

## 五、常见使用问题提示（学员最容易踩的）

### 5.1 网络要求

- 开发板**仅支持 2.4G 频段 WiFi**（不支持 5G）
- 必须与操作电脑处于**同一网络环境**
- 不满足 → 麦克风识别异常、设备连接失败

### 5.2 救砖操作

- **触发条件**：固件烧录过程中设备无响应、按键无灯
- **恢复方法**：**长按 BOOT 键后重启设备**，即可退出烧录模式

### 5.3 外观拓展（待发布）

- 后续将统一发布**开发板定位板、3D 打印外壳的标准文件**
- 学员无需自行测量硬件尺寸
- 可基于标准文件自定义外观

### 5.4 版本更新策略

- 官方会**持续迭代开发板固件**
- 重点修复：Windows 兼容、杀毒软件拦截等问题
- 保持稳定的版本更新频率

## 七、量产导向的开发思维（会议补充·商业化视角）

讲义偏技术（七阶段 + 验证节点），会议更强调**商业化**：

### 7.1 避免的误区

- ❌ **不要只做桌面玩具级产品**——只能在自己桌上跑没有商业价值
- ❌ **不要陷入技术至上**——尽早让产品接触真实用户，根据反馈迭代

### 7.2 量产的现实约束

- 硬件产品**必须量产**才能完成商业化、发挥最大价值
- 量产需要**多岗位配合**：产品 / 工业设计 / 结构 / 硬件 / 嵌入式 / 市场销售
- 学员可在训练营**搭子团组队**，互补不同方向能力
- 硬件开发不可避免对接**工厂、供应链**等实体环节

### 7.3 量产核心注意事项（会议原话）

| 项 | 说明 |
|----|------|
| 工厂烧录包 | 需准备完整、规范、可复现 |
| 操作步骤 | 文档化、可培训 |
| 首件测试记录 | 留档可追溯 |
| 量产链路 | 启动后**停线成本高**，需提前完成全环节验证 |
| 结构可靠性 / 电气安全 | 必须由**专业人员审核把关** |
| 仓储 / 认证 / 供应链 | 全链路成本**从产品定义第一天**就要考虑 |

### 7.4 跨角色协作带来的机会

- 比纯软件开发**更需要跨角色协作**
- 能带来**更多元的就业与创业机会**
- 这也是训练营鼓励组队的核心理由之一

# EasyInput V2.0 开发板新手手册

## 打开方式

双击 `index.html`，或将它拖入 Edge、Chrome、Firefox 等现代浏览器即可。页面和图片均保存在本目录中，不需要联网。

## 内容

- 开发板正面与背面实拍标注；
- 元器件和功能区说明；
- 按键、旋转编码器、灯光、音频、电池及共享电源说明；
- BOOT、下载模式和恢复流程；
- 支持搜索的完整 GPIO 速查表；
- 训练营学习路线、常见误区与已知缺口；
- 桌面、手机和打印样式。

## 资料原则

本文面向硬件初学者，不是制造说明。内容区分为“已确认、实拍可见、项目决定、待确认”；没有完整 BOM 或实板测量依据的信息不会作为确定事实给出。

## 主要依据

- `easyinput-board-cy` 中的原理图、PCB 快照和板级参考资料；
- `easyinput V2.0` 中的 2026-08-17 实拍照片；
- 当前板级合同验证日期：2026-08-05。

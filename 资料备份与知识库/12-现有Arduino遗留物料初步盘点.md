# 现有 Arduino 遗留物料初步盘点

更新日期：2026-08-19

来源：用户提供的四张收纳盒照片。本文是照片级初步识别，型号和电压不清楚的模块必须补拍丝印后才能正式接线。

## 一、结论

这批旧物料足够支持桌宠项目早期的桌面验证，不必马上重复购买全部传感器。最有价值的是杜邦线和原型板、HC-SR04 类超声波模块、Arduino Sensor Shield、RC522 RFID 模块、1602 LCD、Nokia 5110 图形屏以及若干电源和接口小板。

它们应优先接到桌宠套件主控或 Arduino 副控，不要直接占用 EasyInput 的 J4。EasyInput 只通过 UART 发送高层事件。

## 二、照片中较高置信度的物料

| 物料 | 主要用途 | 对桌宠项目的价值 | 注意事项 |
|---|---|---|---|
| 大量杜邦线、彩虹排线、排针 | 传感器、串口和面包板临时接线 | 第一阶段必用 | 最终成品改为规范线束，线色区分 GND、3.3V、5V、信号 |
| USB 线 | 烧录、调试、供电 | 高 | 逐根确认是否支持数据 |
| HC-SR04 类超声波模块 | 距离测量、云台扫描 | 可验证靠近检测和粗略转向 | 常见 Echo 为 5V，接 ESP32 需分压或电平转换 |
| RC522 RFID 模块、卡片和钥匙扣 | 刷卡识别、模式切换 | 很适合做特色交互 | 常用 SPI，通常 3.3V，需确认模块版本 |
| 1602 字符 LCD | 显示距离、温湿度、调试信息 | 适合原型验证 | 需确认并口版还是 I2C 转接版 |
| Nokia 5110/84×48 图形 LCD | 小表情、调试菜单 | 适合早期屏幕试验 | 分辨率低，最终建议用桌宠套件 OLED 或彩屏 |
| Arduino Prototype Shield | 焊接转接、电源分配、固定模块 | 可做传感器试验台 | 需确认是否为 UNO 引脚排列 |
| Arduino Sensor Shield V5 类板 | 多个三针传感器快速连接 | 可做 Arduino 副控试验台 | 不能直接插到 ESP32，需转接 |
| 小型直流电机 | 风扇、转盘、振动实验 | 仅作机构实验 | 需要驱动器和续流保护，不能替代头部舵机 |
| 电源模块、USB 供电模块 | 原型供电 | 可用于低风险台架测试 | 先测输出电压，不能未经确认与 EasyInput 或舵机混供 |
| 按键、LED、阻容、二极管 | 逻辑验证和临时电路 | 中等 | 先按规格分类，不直接混用不明元件 |

## 三、需要补拍确认的物料

照片里还有几块疑似 ESP-01/ESP8266 下载器、继电器或声音模块、旋钮电位器和电池小板，但仅凭照片不能确认型号。请后续给这些模块拍正反面近照，拍清芯片、丝印和引脚。

## 四、在桌宠项目中的使用顺序

### 1. 先用超声波做感知原型

让桌宠头部在左、中、右三个角度测距，比较连续几次结果后朝较近方向转动。它可以演示有人靠近和粗略找方向，但不能可靠识别人，也不建议作为最终隐藏式方案。

### 2. 用 RFID 做自己的特色功能

刷卡后可以唤醒桌宠、切换专注模式、展示模式或儿童学习模式，并让 EasyInput 切换对应工作状态。这个功能比单纯增加一个传感器更容易形成产品故事。

### 3. 最终再换成两个 ToF

毕业作品建议用两枚 VL53L0X 或 VL53L1X，隐藏在桌宠屏幕左右边缘，根据左右距离差微调云台。两个相同 ToF 通常需要用 XSHUT 改地址，或增加 I2C 多路复用器，等套件真实 GPIO 表确认后再定。

## 五、与 EasyInput 的连接边界

EasyInput J4 只有 3V3、GND、UART0 RX/TX，不是通用扩展排针。旧传感器和显示器优先接桌宠主控或 Arduino 副控；EasyInput 发送 LISTENING、WORKING、DONE、USER_NEAR、RFID_MODE=FOCUS 等高层事件。

注意：不要把旧模块的 5V 电源或 5V 信号线直接接到 EasyInput J4 或 ESP32 的 3.3V GPIO；舵机必须使用独立电源。

## 六、下一步

先不用把收纳盒全部倒出来。按主控、显示、传感器、执行器、电源、线材六类粗分即可。优先补拍 HC-SR04、RC522、1602、Nokia 5110、Sensor Shield、电源模块和疑似 ESP-01 小板。桌宠套件到手后，再按它的真实 GPIO 表决定复用哪些旧模块。

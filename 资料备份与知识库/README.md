## 事实优先级

发生冲突时按以下顺序处理：

1. 当前实板明确确认、可复现的实测行为；
2. 可追溯的原理图、PCB、芯片资料和项目源码；
3. `easyinput-board-cy` 规范化板级合同；
4. CY 老师针对当前问题的明确答复；
5. 课程讲义与官方答疑原文；
6. 群内经验、整理稿、通用 ESP32 教程。

低优先级资料与高优先级资料冲突时，不做折中，使用高优先级事实并注明旧说法已被替代。

## 修改原则

- 原件不移动、不覆盖、不删除；
- 新资料先登记来源、日期、版本和哈希，再进入结论；
- 板级硬件事实与某一版固件的产品行为分开记录；
- “构建成功”“烧录成功”“应用在真板运行”是三层不同证据；
- 未取得源码、固件包或实测证据前，未知项保持未知。

# EasyInput 桌面宠物毕业设计：功能发散与产品方案

更新日期：2026-08-19

## 一、先看清楚现成套件是什么

你看到的第一套产品，本质上是一个已经组合好的桌面机器人机构：

- 一块 ESP32-S3 主控板；
- 一块小 OLED 屏幕；
- 麦克风、I2S 功放和扬声器；
- 两个舵机组成的双轴云台；
- 一些金属连接件、紧固件和底座外壳；
- 对应的示例程序和接线资料。

它的价值是把机械、电气和基础程序先准备好，让我们不用从零开始找零件。它不是最终作品，真正的毕业设计价值在于：重新定义它的角色、加入自己的感知和交互、重新设计结构，并与 EasyInput 形成一个统一系统。

## 二、不要把它定义成“两个东西拼起来”

最终产品应该有一个统一的产品概念，例如：

> **AI 工作台伙伴：一把会听懂任务、显示进度、主动面向使用者并在桌面上陪伴工作的 AI 键盘。**

在这个定义下，EasyInput 不是一个外接附件，桌面宠物也不是另买的小玩具，而是同一件产品的两个功能区：

```text
前部：EasyInput AI 键盘
负责实体输入、快捷操作、状态灯、语音入口

后部：AI 桌面伙伴
负责表情、声音、转头、感知使用者和任务状态反馈
```

两者用内部隐藏线束和一个小型连接/扩展板连接，外观上只呈现一个完整产品。

## 三、功能发散：可以增加什么

### 1. 主动面向使用者

这个功能可行，但“超声波自动看人”需要准确理解它的边界。

超声波可以测距离，但单个超声波模块不能知道“人在哪个方向”，也不能可靠识别人。把超声波装在会转的头上，让舵机左右扫描，可以得到一个粗略的距离分布，但容易受到桌面、墙面、衣服和其他物体反射影响。

更适合分阶段实现：

| 方案 | 能力 | 适合程度 | 说明 |
|---|---|---:|---|
| 单个超声波 | 测前方距离 | ★★☆☆☆ | 只能知道前方有没有近物体，不能稳定判断人在哪 |
| 舵机扫描 + 超声波 | 粗略找最近方向 | ★★★☆☆ | 可以做展示，但会有扫描延迟和误判 |
| 左右两个 ToF 测距 | 判断左右距离差 | ★★★★☆ | 体积小、响应快，适合桌面原型 |
| PIR 红外人体感应 | 判断有人移动 | ★★☆☆☆ | 不能精确给出头部转向角度 |
| 8×8 红外阵列 | 判断人体热源方向 | ★★★★☆ | 可以做存在和方向判断，成本及库支持需确认 |
| 摄像头 + 电脑视觉 | 识别人脸并计算角度 | ★★★★★ | 体验最好，但视觉识别多半由电脑或另一块高算力板完成 |
| 毫米波雷达 | 检测人在场、距离和运动 | ★★★★☆ | 适合存在检测，算法和调试复杂度更高 |

推荐路线是：

1. 第一版用一个舵机扫描 + ToF 或超声波做“朝向最近活动区域”；
2. 第二版用左右两个 ToF 做更快的左右判断；
3. 展示版再接电脑摄像头做人脸/人体跟踪，把目标角度通过 UART 发给机器人。

这样既能实现“它会看着我”，又不会把第一版项目卡在复杂的视觉算法上。

### 2. AI 工作状态显示

这是最适合 EasyInput 的核心差异化功能。

它可以显示：

- 正在听你说话；
- 正在理解需求；
- 正在生成图片；
- 正在编译和烧录；
- 等待你确认；
- 任务完成；
- 任务出错，需要人工处理。

屏幕不必滚动代码，可以采用“表情 + 任务名 + 进度 + 简短提示”的方式，例如：

```text
正在生成封面
██████░░░░ 60%
预计还需约 25 秒
```

### 3. 语音状态查询

用户可以直接问：

- “现在做到哪了？”
- “刚才为什么停了？”
- “继续执行。”
- “暂停这个任务。”

EasyInput 负责接收语音，电脑端或任务服务负责提供真实任务状态，桌宠负责用表情、动作和语音反馈。

### 4. 键盘快捷操作与实体交互

EasyInput 原本有按键和旋钮，这些可以和桌宠动作形成统一交互：

- 旋钮：切换任务、调节音量或选择表情；
- 旋钮按压：确认；
- 一个实体键：暂停/继续；
- 一个实体键：召唤桌宠转向自己；
- 长按：进入安全停止或配网模式。

这样键盘不是普通输入设备，而是桌宠的控制台。

### 5. 环境感知

你已有的 Arduino 传感器可以优先接在桌宠副控或自制扩展板上：

- 温湿度：根据环境显示舒适度，或让桌宠提醒通风；
- 光照：自动调整屏幕亮度和表情氛围；
- 距离传感器：判断用户是否靠近、是否离开；
- 触摸传感器：触摸外壳时眨眼或回应；
- 超声波：做近距离避障或粗略找人；
- 旋钮/按键：实体确认、选择和控制；
- IMU：判断桌宠是否被移动或倾斜。

传感器不要为了“数量多”而加入。每个传感器都应对应一个清楚的产品行为。

## 四、推荐的毕业设计主方案

### 产品名称方向

可以暂时叫：

- AI 工作台伙伴；
- 会看着你的 AI 键盘；
- DeskMate AI；
- EasyInput 工作伙伴；
- 面向 AI 工作流的桌面宠物。

### 核心体验

用户坐到桌前，桌宠自动感知有人靠近并转向；用户通过 EasyInput 说出任务；键盘灯和桌宠屏幕同步显示状态；任务执行期间，桌宠保持朝向用户，阶段变化时用表情、动作和语音播报；完成后点头或挥手，遇到需要决策的地方等待用户确认。

### 推荐硬件组成

| 部分 | 第一版 | 展示版 |
|---|---|---|
| AI 主输入 | EasyInput V2.0 | EasyInput V2.0 |
| 桌宠主控 | ESP32-S3 套件主控 | 套件主控 + 自制扩展板 |
| 屏幕 | 0.96 英寸 OLED | 2～3 英寸彩色屏或更大 OLED |
| 运动 | 双轴云台 | 双轴云台，必要时增加一个动作机构 |
| 感知 | 1 个 ToF 或超声波 | 左右 ToF、光照、触摸或电脑摄像头 |
| 通信 | 3.3V UART | 隐藏 UART，或专用扩展板连接器 |
| 供电 | 两路独立供电，共地 | 统一电源管理和保险/保护 |
| 结构 | 3D 打印组合壳 | 一体化外壳、可拆后盖、隐藏线束 |

## 五、外观和结构整合方式

### 方案 A：键盘后置“颈部机器人”

前面是 EasyInput 键盘，后面是一个略高于键盘的桌宠头部。头部通过短立柱或隐藏云台安装在键盘后方。

优点：最符合你的设想，桌宠自然地面向使用者；键盘和头部形成明确的一体产品。

结构要点：

- 键盘底座和桌宠底座共用一件外壳；
- 头部转动中心略高于键盘后缘，避免视线被键帽遮挡；
- EasyInput、桌宠主控和电源分仓；
- 内部预留 USB、BOOT、J4 和维护口；
- 线束从键盘后方的隐藏线槽进入桌宠底座。

这是我最推荐的毕业设计形态。

### 方案 B：键盘后方的可拆卸“伙伴模块”

桌宠固定在键盘后方，但通过滑轨、燕尾槽或磁吸定位结构连接，需要时可以取下单独使用。

优点：兼顾一体化外观和维护便利；可以展示“键盘模式”和“独立桌宠模式”。

这不是把两个东西简单分体，而是一个主产品中的可拆功能模块。

### 方案 C：键盘上方的“屏幕头冠”

桌宠头部不做明显底座，而是通过横向支架或后置立柱悬在键盘上方，类似一个会转动的屏幕头。

优点：桌面占用更小，视觉识别度高。

风险：重心、支架刚度、舵机扭矩和结构振动需要认真设计。

### 方案 D：键盘右后方的“工作台助手”

EasyInput 保持完整键盘形态，桌宠放在右后侧，共用一个更大的工作台底座，视觉上属于同一个产品家族。

优点：不遮挡键盘，结构和散热容易处理；适合把屏幕朝向用户。

缺点：一体化感弱于后置颈部方案。

### 方案 E：显示器下方的“屏幕伴侣”

键盘放在桌面，桌宠通过一个夹持或底座结构安装在显示器下方，形成面向用户的交互节点。

优点：屏幕高度和视线更自然；可做更漂亮的外壳。

缺点：机械安装受显示器尺寸和桌面环境影响，通用性较差。

## 六、怎样让它真正有自己的设计

“有自己的东西”不等于额外加很多传感器，建议至少在以下四层做原创：

### 1. 产品定义原创

不是普通桌面宠物，而是“AI 工作流状态伙伴”。它的表情、动作和语音都围绕任务过程服务。

### 2. 结构原创

- 统一键盘和桌宠的外壳语言；
- 隐藏线束和可维护分仓；
- 设计可拆云台和模块化传感器位；
- 让屏幕、麦克风和扬声器有明确的声学及视线布局；
- 通过 SolidWorks 完成参数化设计、装配和运动干涉检查。

### 3. 交互原创

- 键盘旋钮与头部动作联动；
- 语音状态查询；
- 根据任务阶段显示不同表情；
- 需要人工决策时主动转向并等待确认；
- 用户离开时进入低功耗待机，回来时主动欢迎。

### 4. 工程原创

- 自定义 UART 事件协议；
- 自制传感器扩展板或转接板；
- 记录电源、舵机、屏幕和通信的测试数据；
- 设计故障恢复、手动停止和安全姿态。

## 七、跟随使用者的现实方案

“人走到哪，它就一直看着人”可以分成三个等级：

### 等级 1：存在和靠近

用 PIR 或 ToF 判断有人靠近。有人时唤醒，没人时进入待机。实现简单，但不能准确追踪方向。

### 等级 2：左右方向跟随

使用左右两个 ToF，或让一个 ToF 随头部小范围扫描，根据左右距离差调整云台角度。适合第一版展示。

### 等级 3：真正的人脸/人体跟随

使用电脑摄像头、手机摄像头或高算力视觉模块计算目标位置，再把目标角度通过 UART/Wi-Fi 发给桌宠。体验最好，但视觉算法不适合全部压在普通 ESP32-S3 上。

建议毕业设计先做到等级 2，做出稳定、可解释、可重复的跟随；如果课程后期有时间，再把等级 3 作为高级功能。

## 八、推荐的系统架构

```text
EasyInput V2.0
  ├─ 按键和旋钮：用户控制
  ├─ 麦克风：语音输入
  ├─ 板载灯：键盘侧状态
  └─ UART0：发送任务事件和动作意图

桌宠 ESP32-S3 套件
  ├─ OLED：表情和进度
  ├─ 双轴舵机：转头、点头
  ├─ 麦克风/扬声器：可选的本地表现
  └─ 传感器扩展：距离、光照、触摸

电脑或任务代理
  ├─ 产生真实任务状态
  ├─ 进行复杂 AI/视觉处理
  └─ 通过 EasyInput 或串口发送事件
```

第一版只需要实现少量事件：`IDLE`、`LISTENING`、`THINKING`、`WORKING`、`DONE`、`ERROR`、`USER_NEAR`、`USER_LEFT`。

## 九、分阶段毕业设计路线

### 阶段 1：现成套件单独跑通

确认屏幕、音频、双轴云台和源码可以独立工作。

### 阶段 2：EasyInput 有线联动

用 UART 发送六种状态，桌宠根据状态改变表情和动作。

### 阶段 3：加入一个感知功能

优先加入“有人靠近 + 左右方向判断”，不要一开始接很多传感器。

### 阶段 4：一体化结构

以键盘后置颈部方案为主，设计统一底座、隐藏线束、维护口、屏幕视线和云台安装。

### 阶段 5：AI 工作流闭环

用户语音提出任务，电脑或 Agent 产生状态，键盘灯、桌宠屏幕和头部动作同步反馈。

### 阶段 6：高级跟随与展示

增加左右 ToF、环境感知或电脑视觉跟随，完成结构爆炸图、状态机、协议、测试记录和演示视频。

## 十、我的最终建议

最推荐你做：

> **键盘后置一体式 AI 工作台伙伴**：前部是 EasyInput 键盘，后部是一个双轴可动的桌宠头部；它通过有线串口接收 AI 工作状态，屏幕显示表情和进度，能够感知用户是否在场，并在一定范围内主动转向用户。

这个方案有四个层次的完成度：

1. 买现成套件，先得到可动的头部和屏幕；
2. 通过 UART 与 EasyInput 形成真正的双板系统；
3. 用传感器加入“会看人”的感知能力；
4. 用 SolidWorks 设计一体化外壳、底座和隐藏线束。

这样评审看到的不是“键盘 + 机器人套件拼接”，而是一件经过产品定义、结构设计、电子连接、固件开发和真机验证的 AI 硬件作品。

## 十一、当前不要过早承诺的事项

- 商品图不能证明套件一定开放所有 GPIO；
- 不能仅凭“ESP32-S3”判断它能直接使用 EasyInput 的 UART；
- 超声波不能独立完成可靠的人脸识别和连续跟随；
- 两块板的语音、AI 和电源是否能整合，要看实际源码和接口；
- 现成套件的主板、舵机和外壳尺寸需要到手实测后才能做最终结构。

因此建议先买一套资料完整的全套版，先跑通并获取它的源码、引脚表和尺寸，再开始正式画一体化外壳。

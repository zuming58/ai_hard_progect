## 一句话总结

Codex Micro 不是让模型变快的工具，而是把 **"Agent任务状态"** 从屏幕里搬到了桌面上——六枚状态灯用颜色告诉你任务是否需要人介入。核心芯片是 **ESP32-S3-WROOM-1**，没有本地AI计算。

## 01 六枚状态键，才是这台设备真正的产品

**状态键功能**：
- 可以绑定Codex任务
- 默认逻辑：跟随最近更新的六个任务
- 可改成：置顶任务、优先显示等待输入/未读/运行中的任务、逐一手动分配
- 单击：后台切到对应任务
- 双击：把Codex窗口带到前台

**六色状态灯定义**：

| 颜色 | 状态 |
|------|------|
| ⚪ 白色 | 空闲 |
| 🔵 蓝色 | 思考中 |
| 🟢 绿色 | 完成 |
| 🟡 琥珀色 | 需要输入 |
| 🔴 红色 | 错误 |
| ⚫ 熄灭 | 没有分配任务 |

**真实体验**：
- 设备确实参与了真实任务状态通信，不是静态亮灯
- 日志显示硬件服务持续收到线程状态与RGB配置响应
- 出现过RGB请求超时
- **矛盾点**：任务状态已经接通，通信却还会偶尔掉链子
- 使用强度决定六个位置的价值：只开一两个任务时大部分闲着；多Agent同时运行时才和普通宏键盘拉开差别

### 作者判断

> **Codex Micro没有让模型变快，也没有创造电脑上做不到的新操作。它把"任务是否需要人介入"同步到了桌面上。**
>
> 这件事听上去很小，但它正好碰到了多Agent工作流里一个越来越频繁的动作：反复打开窗口，只为确认"它做完了吗"。

## 02 第一次配置：入口很完整，连接却没有外观那么从容

**做得好的地方**：
- 设备设置直接长在Codex里（桌面端左下角进入设备页面）
- 不需要先理解QMK、VIA或键码
- 原生入口比多送几个快捷键更重要

**配置项**：
- 输入监控权限
- 灯光亮度、自动调暗
- 六枚状态键关注什么
- 旋钮做什么
- 语音键怎样触发

**连接问题**：
- macOS输入监控已授权，但连接栏显示"未检测到"
- USB排障中遇到**两次HID读取中断**，最长一次约71秒
- 有时设备会自行恢复，有时需要重新连接
- 已为Karabiner加忽略规则，仍遇到卡顿（第三方输入工具不是全部原因）
- Bluetooth可以识别设备
- **结论**：它能用，连接还不够让人放心

> 对于一块负责报告任务状态的硬件，连接本身也必须像状态一样可信。

## 03 旋钮、摇杆和语音键：逻辑能讲通，长期手感还没有结论

### 正面控件一览

旋钮、平面摇杆、六枚智能体按键、触摸区、命令键、语音按键。

### 各控件评价

| 控件 | 评价 |
|------|------|
| **白色旋钮** | 适合连续变化的操作（编辑器导航、推理级别调整等）。是否有价值取决于有没有需要反复调节的量。 |
| **黑色平面摇杆** | 路径短，但需要记住方向。出厂映射含切换Plan模式、前进/后退历史、显示/隐藏侧栏。映射经常变化的话就要重新记。 |
| **长条语音键** | 触发语音，不负责收音（调用电脑麦克风）。按住说话，松开停止，双击免按住录音。改变的是触发方式，不是收音质量。 |
| **命令键** | 把接受、拒绝、新建、继续任务变成实体动作。涉及代码改动时仍要先看清上下文。 |

### 与Stream Deck的区别

> Codex Micro把屏幕上的可变标签换成了**固定的位置、形状和灯色**。

## 04 拆开它，是为了看看刚才的体验从哪里来

拆机验证三个问题：按键和状态灯怎样组织、有没有本地AI计算、物理层级是什么。

### 上层PCB：按键和灯光在一起

- 13处机械轴体背部结构
- 灯光器件分布在按键周围
- 输入与状态反馈在同一块控制面上
- 灯光不是游离于按键之外的效果，而是交互的一部分

### 下层控制板：它是一台控制器，不是一台本地AI

- 核心模组：**ESP32-S3-WROOM-1**
- 旁边有RESET、BOOT、排线连接器
- **没有独立NPU**
- **没有证据表明Codex模型运行在设备本地**
- Codex Micro负责：输入、灯光、通信、供电
- 仍依赖电脑端Codex及其背后的服务完成任务

### 物理层级

```
上层按键PCB ←(FFC柔性排线)→ 下层控制板 + 软包电芯
        ↓
半透明框体 + 铝制底座
```

### 230美元的显性投入

- CNC铝制底座
- 定制键帽
- 灯光与无线控制
- 与Codex的原生联动

> 没有BOM和制造数据，不能判断各部分成本占比。更现实的问题仍是：这套整合能否稳定工作。

## 05 230美元，值吗？

### 不划算的角度

- 没有缩短模型运行时间
- 大部分动作能通过键盘或其他控制器完成
- 寄到中国近2400元，性价比更难算

### 值得的角度

- 每天同时维护多个Codex任务的人，不用反复打开窗口就知道哪里需要处理
- 六枚状态键提供了普通宏键盘没有的体验
- 机械键盘/桌面控制器爱好者、OpenAI联名硬件收藏者有另一套价值判断

### 不适合的人

- 偶尔使用Codex的人
- 主要需要跨应用快捷键的人
- 期待内置麦克风的人
- 期待本地AI或脱离电脑独立运行的人

---

## 最终判断（FINAL SIGNAL）

> **Codex Micro最值得保留的不是某个快捷键，而是"Agent什么时候需要人介入"这件事终于有了一个屏幕之外的位置。**
>
> 这个变化值不值2368.71元，取决于那六个位置在你的日常工作里，究竟有多忙。

# 已知缺口与勘误

## 尚未取得或尚未确认

以下内容不能从现有截图可靠补全，任何开发输出都要明确标注为未知：

- 原始 ECAD 工程导出的最终 net/pin table；
- 可追溯的完整 BOM 文件；Skill 打包资料中不含可用的完整 BOM；
- Gerber、钻孔、贴片坐标、装配图及 DRC/ERC 报告；
- D19/D20 与其他可选器件在当前批次的实际 DNP/NC 状态；
- `V_LED` 在电池与 USB 供电下的实际电压，以及 3.3 V LED-DIN 的高电平裕量；
- USB ESD 摆放、USB 差分、天线 keepout 和 KEY_WAKE 二极管方向的制造文件复核；
- GPIO8 拉高后的电源轨波形、静置/连接/音频/灯效电流和 Deep Sleep 电流；
- GPIO8 拉高后对所有器件与开发板批次都成立的最短稳定时间；
- 各批次开发板之间是否存在未反映到丝印的装配差异。

没有证据时使用 `unknown`，不要从 PCB 渲染图、器件外观或另一个批次反推料号和装配状态。

## 当前硬件资料冲突

旧版硬件说明曾含有“关机后按住 BOOT 再上电”的描述。该段已被硬件负责人在 2026-08-05 对当前实板的确认取代：

- 进入：开机状态短按并松开 BOOT；
- 退出：关机，再开机。

Skill、测试步骤和新文档都不得继续传播旧流程。

## 必须拦截的历史错误

| 错误说法 | 当前正确事实 |
| --- | --- |
| S1=GPIO1 | S1=GPIO2 |
| S5=GPIO0 | S5=GPIO1；GPIO0 只用于 BOOT |
| S6/S7=GPIO5/GPIO6 | S6/S7=GPIO6/GPIO7 |
| PWR_EN=GPIO7 | PWR_EN=GPIO8，高有效 |
| GPIO8 只是 LED 开关 | GPIO8 是 LED/MIC/SPK 共享电源生命周期信号 |
| 发黑帧等于关闭电源 | 黑帧只熄灯，不改变 GPIO8；运行中是否关闭共享电源由目标项目决定，并须先安全停止所有消费者 |
| SEN_CHRG 高=已充满 | 外部供电存在时，高=充电中，低=充满 |
| KEY_WAKE 能识别具体按键 | KEY_WAKE 只汇总唤醒，之后必须重扫 |
| PCB V2.1 是独立板型 | 它与 EasyInput V2.0 / 固件板型别名 v2 是同一当前基线 |
| BOOT 必须按住并配合上电 | 当前板开机状态短按并松开即可 |
| 板上有单独 RESET 键 | 没有供用户操作的独立 RESET/EN 键 |

## 变更门

只有取得新的原理图/PCB/BOM 或明确的新批次实板证据，才能修改 `board-contract.json`。修改时同步：

1. 更新对应 reference；
2. 替换资产并更新 SHA-256；
3. 记录变更来源、日期和开发板身份；
4. 运行 Skill 自带的合同测试；
5. 仅对用户明确指定或授权的目标项目运行 drift checker，并重新执行相关 host 测试与实板验收。
